## 📌 About

This repository contains implementations of core **data structures** and **algorithms** in JavaScript. Each directory represents a different topic or structure, helping you understand fundamental concepts from scratch.

📍 It’s designed for:
- Beginners learning DSA with JavaScript
- Developers preparing for coding interviews
- Anyone wanting clean, easy-to-read DSA solutions
